## Transhub 平台教学开发任务指南

### 资源简介

Transhub 实验文档用于指导学生完成本地调试环境配置、平台使用准备以及开发任务一至五的实验操作。该资源适合作为学生开展协议栈开发实验时的主要操作指南。

### 主要内容

- **本地安装指南**：指导学生配置 Transhub 本地调试环境，完成平台运行前的准备工作。
- **开发任务一：数据包封装**：完成基础数据包结构设计、封装与解析相关实验。
- **开发任务二：ACK 机制**：实现确认应答机制，理解可靠传输的基础流程。
- **开发任务三：丢包检测**：实现丢包发现、重传判断和异常传输处理逻辑。
- **开发任务四：基础拥塞控制**：实现基础拥塞控制策略，观察网络状态变化对传输性能的影响。
- **开发任务五：自定义拥塞控制算法**：在前序任务基础上设计并实现自定义拥塞控制方案。

### 使用建议

建议学生按照本地安装指南和开发任务一至五的顺序逐步完成实验，并结合 Transhub 平台评测结果持续调试和优化实现。
