## Transhub 教学与竞赛资源

本仓库用于存放 Transhub 平台配套的课件、教学计划、开发任务指南和讲解视频等资源，面向计算机网络课程教学、实验训练和竞赛实践场景。

### 资源目录

| 目录                                           | 资源类型 | 说明                                                                                 |
| ---------------------------------------------- | -------- | ------------------------------------------------------------------------------------ |
| [`01.理论基础教学课件`](./01.理论基础教学课件/) | 教学课件 | 系统介绍“一人一栈”计划的预备知识、建设背景、平台功能、评测方式及赛教融合实施思路   |
| [`02.一人一栈计划书`](./02.一人一栈计划书/)     | 教学计划 | 包含“一人一栈”计划书和课程大作业时间表，说明训练目标、核心任务、阶段进度和提交节点 |
| [`03.开发任务指南`](./03.开发任务指南/)         | 实验文档 | 指导学生完成本地调试环境配置、平台使用准备以及开发任务一至五                         |
| [`04.开发任务讲解视频`](./04.开发任务讲解视频/) | 讲解视频 | 通过案例视频讲解本地调试环境配置和开发任务一至五的操作细节                           |

### 使用建议

- **教师**：可结合教学课件和教学计划组织课程导入、实验安排、阶段检查和课程评价。
- **学生**：建议按照开发任务指南依次完成本地环境配置和开发任务，并结合讲解视频理解关键操作。
- **竞赛组织者**：可参考教学计划和实验文档设计训练流程、任务节点和评测安排。
