## Transhub 平台教学计划

### 资源简介

本资源包含《中国人民大学“一人一栈”计划书》与《2026春季学期《计算机网络》课程“一人一栈”计划（大作业）时间表》，用于说明 Transhub 平台在课程教学中的整体安排和实施路径。

### 主要内容

- **训练目标**：明确学生通过 Transhub 平台完成协议栈开发与网络实验训练的学习目标。
- **预备知识**：说明参与课程实验和开发任务所需掌握的基础知识。
- **核心任务**：概述“一人一栈”计划中的主要开发任务和实验要求。
- **阶段进度**：给出课程推进过程中的阶段安排和任务节奏。
- **提交节点**：说明各阶段材料、代码和实验结果的提交时间要求。
- **里程碑要求**：明确关键阶段应达到的功能实现和评测目标。
- **课程组织方式**：为教师开展案例教学、实验教学和大作业管理提供整体规划参考。

### 适用对象

- **教师**：用于设计课程安排、组织实验任务和管理教学进度。
- **学生**：用于了解课程目标、任务节点和阶段性要求。
