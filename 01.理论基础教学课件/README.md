## Transhub 平台教学课件

### 资源简介

Transhub 教学课件系统介绍了“一人一栈”计划的预备知识、建设背景、平台功能、评测方式及赛教融合实施思路，适合作为教师开展课程导入、平台介绍和实验任务说明时的教学材料。

### 主要内容

- **预备知识**：介绍开展 Transhub 实验与“一人一栈”计划所需的基础背景。
- **建设背景**：说明平台建设目标、课程教学需求和赛教融合背景。
- **平台功能**：介绍 Transhub 平台的核心能力、使用场景和功能模块。
- **评测方式**：说明平台任务提交、结果评测和反馈机制。
